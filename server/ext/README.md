# WomanLive 拡張機能 (個人向け追加開発)

WomanLive 本体を**無改変**（本体ファイルは変更しない）まま、以下の機能を追加するアドオンです。
すべての追加要素は `server/ext/` 配下に閉じています。

## 仕組み（再ビルド不要・本体改変無）
- **読み込み**: 付属の `womanlive-ext.bat`で起動すると、
  `server/index.js` を**書き換えずに**拡張をロードします。
- 追加データは `videos.db` の**新規テーブル**（`ext_*`）に保存。既存テーブルは無改変。

## 導入方法
1. 配布 zip 内の **`server` フォルダ**と **`womanlive-ext.bat`** を、WomanLive の**ルート**（`womanlive.bat` と同じ場所）へそのままコピー（`server` が既存の `server` に統合され `server/ext` ができればOK。既存ファイルは上書きされません）。
2. WomanLive を一度終了し、**`womanlive-ext.bat`** で起動すると拡張が有効になります。
3. 設定画面に「拡張機能：カバー画像」などの項目が増えていれば正常に導入されています。

## 追加機能の一覧
記載順の概要です（各機能の詳細は以下の同名の節を参照）。
- **動画情報**: カバー画像 / 拡張メタデータ / 関連動画アルゴリズム修正 / スクリーンショット関連（枚数表示・ソート・表示サイズ変更） / コマ送り / 各種ソート機能追加 / 動画タグ編集機能改善（グループ対応）/ DMM(FANZA) API連携
- **出演者**: 出演者一覧（関連動画数の表示・出演数ソート）/ 出演者タグ機能（グループ対応）/ 出演者タグ自動付与
- **一覧・ナビゲーション**: メーカー一覧 / シリーズ一覧 / タグ一覧 / 公開カレンダー / ブックマーク / ナビゲーション統一（ヘッダー・メニュー・アイコン・WomanLiveEX 配色）
- **操作・データ管理**: 一括操作 / 一覧ページの一括削除 / メタデータ置換 / メンテナンス（参照されていないデータの削除）/ バックアップ

## カバー画像
動画と同名の画像を指定フォルダから自動割り当てし、動画ページのスクリーンショット欄の先頭に表示（クリックで拡大）。
- 例: 動画 `AAA.mp4` に対し、フォルダ内の `AAA.jpg`（または .png/.webp 等）を自動表示。
- 設定画面「拡張機能：カバー画像」でフォルダを指定して保存。
- DMM 商品検索で取得したカバーは `ext_video_cover` テーブルに保存（フォルダ未設定でも表示可）。

## 拡張メタデータ
評価(★)・表示名・品番・公開日・シリーズ名・メーカー・レーベル・作品監督・出演者・ジャンルを、
各動画ページの「✎ 詳細情報を編集」から編集／表示します。
- 品番・シリーズ・メーカー等はクリックで同条件を検索（後述の「検索トークン」を自動付与）。評価は検索・ソート可。
- 「表示動画名」を設定すると、一覧・検索でファイル名の代わりに表示されます。
- 検索画面右上の**「表示設定」に「動画表示名で表示する」**を追加しています（既定はON）。
  OFF にすると表示動画名を使わず、本家どおりファイル名で表示します。一覧・動画ページ・関連動画に効き、
  設定はブラウザに保存されます。並び替えの「表示名」は OFF でもそのまま使えます。

## 関連動画（メタデータ類似・事前計算）
動画ページの「関連動画」を、拡張メタデータの一致度で選出します。
- **本体の既定**: ファイルパスが前後する12件（実質「同フォルダ・ファイル名が近い動画」）のみ。
  メタデータを考慮していないため、これを類似度スコアリングに置き換えます。
- **採点**: シリーズ／出演者／メーカー／レーベル／監督／ジャンル／タグ／公開時期／評価の一致を計算し、
  上位12件を返します（**シリーズ最重視**が既定）。**重みは設定画面で調整可能**。
- **事前計算**: 結果は `ext_related` テーブルに保存。動画のメタを編集すると、その動画分は自動で再計算されます。設定画面「拡張機能：関連動画（重み付け）」の「全再計算」で全動画を一括計算も可能です。

## スクリーンショット関連（枚数表示・ソート・表示サイズ変更）
検索結果カードに、各動画のスクリーンショット枚数を表示し、枚数で並べ替えできます。各動画ページのスクリーンショット欄にスライダーを追加し、表示サイズを変更できます（画像そのもの・解像度は変更しません）。
- フォルダ名の右・ブックマークボタンの左に、単色カメラアイコンでスクリーンショット枚数を表示。
- 検索バーに「スクショ数」ソートを追加。を表示。
- 表示サイズは**80px〜640px**の範囲で変更（既定 160px。16:9 の縦横比を維持）。
- カバー画像（先頭のカバーカード）も同じサイズに追従します。
- 変更したサイズはブラウザに保存され、次回訪問時も引き継がれます。

## コマ送り
動画を1コマずつ進める／戻せます。本家のホイール操作（5秒送り）はそのままです。
- **`.`** で1コマ送り、**`,`** で1コマ戻し。再生中に押すと一時停止してから動きます。
  文字入力中や拡張のダイアログを開いている間は反応しません。
- **プレイヤー上で Shift+ホイール**でも同じ操作。下方向で送り、上方向で戻しです。
- **スマホやタブレット**では、一時停止中のプレイヤーに半透明のボタンを重ねます。
  左端で1コマ戻し、中央で再生、右端で1コマ送りです。再生中とマウス操作の端末では表示しません。
  本家の横スワイプ（滑らせた距離で早送り・巻き戻しする操作）はそのまま使えます。
- 操作すると画面上部に、時刻とフレーム番号・フレームレート（例: `▶ 1:40.033 (2999F / 29.97fps)`）を
  1秒ほど表示します。
- フレームレートは ffprobe で取得し、動画ごとに1回だけ調べて以降は使い回します
  （本家は保持していないため。追加テーブルは作りません）。
- **変換再生（トランスコード）の動画はコマ送りできません**。セグメントを取り直す再生方式のためで、
  操作すると1回だけ通知します。ファイルをそのまま再生できる動画（mp4 など大半）が対象です。

## DMM(FANZA) 商品検索によるメタデータ自動設定
各動画ページの右下「🔍」ボタンから、品番で FANZA 商品情報を検索しメタデータへ自動設定します。
1. 設定画面「拡張機能：DMM(FANZA) 商品検索API」に API ID とアフィリエイトID を登録（各自の DMM アカウントで取得）。
2. 動画ページで🔍を押すと、品番(model_no)で検索。品番未設定ならエラー。
3. 結果が1件ならプレビュー → 「設定する」で反映。複数なら選択 → プレビュー → 反映。0件なら通知。
4. 反映内容: title→表示動画名 / date→公開日 / genre→ジャンル / series→シリーズ名 /
   maker→メーカー / actress→出演者(自動作成) / director→作品監督 / label→レーベル。
   (品番・評価は維持。カバー画像が未設定なら商品画像を取得して設定)
- **ジャンルだけは上書きせず、既存 + FANZA の和集合**にします(重複は除外・既存の並び順は保持)。
- **FANZA 側が空だった項目は、既存の値をそのまま残します**。確認画面には値のある項目だけを表示するので、
  そこに出ていない項目は変更しません(出演者情報を持たない商品を反映して、手で入れた出演者が消える問題への対応)。
- 商品の探し方は、売り場(動画→通販)ごとに次の順で試し、最初に見つかったものを使います。
  1. 品番をそのままキーワード検索 → 2. cid(`aarm00004` 形式)で厳密一致 → 3. cid 形の文字列をキーワード検索
  3 は content_id に接頭辞が付く作品のための逃げ道です(例: `TOTTE-283` の content_id は `1totte00283` で、
  1 と 2 のどちらでも 0 件になります)。

## 出演者一覧 (/performers)
ホーム画面の「出演者一覧」から開きます。
- **各画像の右上に関連動画数**をバッジで表示。
- ソート: 評価 / 出演数（関連動画数。評価の右） / ふりがな / 身長 / 体重 / バスト / カップ数 / ウェスト / ヒップ / 年齢 。**選択したソートはブラウザに保存され、ページを離れても次回表示時に復元されます**。
- 絞り込み: 出演者タグ / 「別名・氏名が重複する出演者のみ」(同一人物の重複登録を発見)。
- 「🗑 関連動画のない出演者を一括削除」: どの動画にも登録されていない出演者をまとめて削除可能。
 
## 出演者ページ
`/performer/:id`。氏名・ふりがな・誕生日・スリーサイズ・別名・出演者タグ等の編集、
画像アップロード＋正方形トリミング、関連動画・関連スクリーンショットを表示します。
- 動画ページの出演者の顔写真クリックで開きます。名前や🔎から同じ出演者を検索。
- **関連動画の件数**を「関連動画（N）」と見出しに表示します（N は出演している動画数）。
- **関連スクリーンショット**は関連動画と同じサムネイルサイズで表示します。見出し右の
  「最近」「ランダム」で切り替え可能。

## 出演者タグの自動付与
設定画面の「拡張機能：出演者タグ 自動付与ルール」で、条件に合う出演者へ自動でタグを付けます。
- ルール = 条件(フィールド・演算子・値) → 付与タグ。例: 身長 ≧ 170 → 高身長。
- フィールド: 身長/体重/バスト/ウェスト/ヒップ/カップ数/評価/年齢/血液型。
  年齢は誕生日から自動算出。カップ数や血液型は文字比較(D≧C など)。
- **出演者側にその項目が登録されていない場合、そのルールは不一致として扱います**(どの演算子でも付与しません)。
  未登録を空文字として比較していたため、カップ数の「≦ D」や「≠ F」が未登録の出演者全員に当たっていた問題への対応です。
  評価は未評価でも 0 が入るため、関連動画の平均評価と同じく未登録として扱います。
- 「適用」で全出演者へ一括付与(冪等)。
- 「同期」チェック時は、条件に合わない出演者から「ルールのタグ」を外します  (ルールに無いタグや手動タグはそのまま)。

## メーカー一覧 (/makers)
ホーム画面と右上メニューの「メーカー一覧」から開きます。動画に設定されたメーカーを横長のリストで表示します。
- **メーカー画像**は 1:1。既定はメーカー名から生成した無地背景に名前を表示し、画像を登録すると差し替わります。
  右上に動画本数、右下の編集ボタンから画像を登録します(ローカル画像を正方形に切り取り。出演者画像と同じ操作)。
- 画像とメーカー名のクリックで、そのメーカーを検索(`@maker:"名前"`)。
- **平均評価**はそのメーカーの動画の評価の平均(評価0=未評価は計算から除外。全て未評価なら「評価なし」)。
- **キャッチコピー**は名前の下。クリックでその場で編集でき、Enter で保存・Esc で取り消しです。
- **TOP10タグ**はそのメーカーの動画に付いたタグを多い順に10個。クリックでメーカーとタグの AND 検索
  (`@maker:"名前" tag:"タグ"`)。
- **レーベル一覧**は開閉式で、`レーベル名(本数)` を本数の多い順に表示します。クリックでそのレーベルを検索。
  レーベル未設定の作品は **「レーベルなし」として本数によらず末尾**に置き、クリックすると
  そのメーカーのレーベル未設定の作品を検索します(`@maker:"名前" label:none`)。
- **FANZAリンク**は右下。リストページURLが登録されているときだけ表示し、新しいタブで開きます。
- ソート: メーカー名 / 動画本数 / 評価。**選択したソートはブラウザに保存され、ページを離れても次回表示時に復元されます**。
- 右端の「⋮」から**メーカー情報編集**(ふりがな・キャッチコピー・リストページURL)と、**メーカー情報取得**を実行できます。

### メーカー情報取得（DMM メーカー検索API）
「⋮」→「メーカー情報取得」で、FANZA から**読み仮名**と**リストページURL**を取得します。
API ID とアフィリエイトID は DMM 商品検索と同じ設定を使います。
- メーカー名が完全一致すれば確認画面へ。一致しなければ**候補の一覧**を出すので、選ぶか、
  名前を変えて検索し直してください。設定するかどうかは確認画面で決めます。
- **メーカー名そのものは変更しません**(動画側のメタデータなので、名前を変えるときはメタデータ置換を使います)。
- MakerSearch API はキーワード検索を持たず `floor_id` が必須のため、FANZA 動画のメーカーを全件取得して
  サーバー側に1時間キャッシュし、名前の突き合わせは拡張側で行います(初回だけ数秒かかります)。
- メーカー情報は `ext_makers` テーブルに保存し、バックアップの対象にも含めています。

## シリーズ一覧 (/series)
ホーム画面の「シリーズ一覧」から開きます。
- 代表サムネイル / シリーズ名/ 平均評価
- 平均評価はシリーズ内動画の評価の平均（評価0=未評価は計算から除外。全て未評価なら「評価なし」）。
- ソート: シリーズ名 / 動画本数 / 評価。**選択したソートはブラウザに保存され、ページを離れても次回表示時に復元されます**。
- サムネイルや名前のクリックで、そのシリーズ名で検索（`@series:"名前"`）。

## タグ一覧 (/tags)
ホーム画面と右上メニューの「タグ一覧」から開きます。登録動画のタグをサムネイル付きで一覧表示します。
- サムネイル / タグ名 / 動画本数
- **既定サムネイル**はタグ名から生成した無地背景にタグ名を表示。各タグに**カスタムサムネイル**を登録すると差し替わります。
- **サムネイル編集**: 右下の編集ボタンで**スクリーンショット選択画面**を開きます。
  - 当該タグが付いた動画のスクリーンショットから**ランダムに9枚**（3×3）を表示。
  - 下部に **「決定」「他の画像へ更新」「ローカルから選択」** の3ボタン。
    - **決定**: 1枚選ぶと押下可能、選んだスクショをタグサムネイルへ設定
    - **他の画像へ更新**: 9枚を再抽選
    - **ローカルから選択**: 従来どおりローカル画像を 16:9 に切り取って登録
- サムネイルやタグ名のクリックで、そのタグで検索（`@tag:"名前"`）
- ソートはタグ名 / 動画本数 / **プリセット順**。**選択したソートはブラウザに保存され、ページを離れても次回表示時に復元されます**。

## 公開カレンダー (/release-calendar)
ホーム画面の「公開カレンダー」から開きます。公開日(メタデータ)で年月別に動画をグループ化。
公開日が未設定の動画は「未分類」にまとめます。月/年/未分類をクリックでその条件の検索へ。

## ブックマーク
動画をフォルダ分けしてブックマークできます。

## メタデータ置換
設定画面の本家「タグ置換」を「**メタデータ置換**」に差し替え、タグ以外のメタデータも一括置換できるようにします。
- 置換できる種別: **タグ / ジャンル / 出演者 / シリーズ名 / メーカー / レーベル**。
- **完全一致のみ**置換します(部分一致では置換しません)。置換前に確認ダイアログが出ます。
- タグは本家と同じ保存形式(前後を改行で囲む)を扱い、**本家のプリセットと拡張のグループレイアウト**も追従します
  (グループ見出しの `# 名前` は置換対象外)。
- 出演者は出演者マスタの名前を変更します。動画側は出演者IDで持っているのでそのまま追従します。
  置換後の名前が既に登録済みのときはエラーにします(統合は出演者ページで行ってください)。
- 本家のセクションは非表示にして同じ位置へ差し込みます。見た目は本家のクラス名を借りて再現します。
- 実装: `server/ext/routes/replace.js`、`public/settings.js`、
  API `GET /ext/api/metadata/replace-kinds`, `POST /ext/api/metadata/replace`。

## 一覧ページの一括削除
シリーズ一覧・出演者一覧・タグ一覧で、選んだ項目を全動画のメタデータから取り除きます。
操作と見た目は検索結果の一括操作(選択モード)と同じです。
- 右下のボタンで選択モードに入り、カードをクリックして選択します。「表示中をすべて選択」「選択をすべて解除」も同じ位置です。
- 1件以上選ぶと「⋮」が出て、そこから削除します。**削除する名前の一覧と件数を確認ダイアログで表示**します。
- 消えるのはメタデータの値だけで、**動画そのものは削除しません**。
  - シリーズ: 動画のシリーズ名を空にします。
  - タグ: 本家 `metadata.tags` から取り除き、**本家のプリセットと拡張のグループレイアウト**からも消します
    (グループ見出しの `# 名前` は対象外)。
  - 出演者: 動画側の紐づけを外し、出演者マスタからも削除します(0本の出演者が一覧に残らないようにするため)。
- 実装: `server/ext/public/listselect.js`、`routes/replace.js`、API `POST /ext/api/metadata/delete`。

## メンテナンス（参照されていないデータの削除）
動画ファイルが無くなったあとも残る拡張データを削除します。
- 本家のクリーンアップ(`DELETE /api/maintenance/metadata`)は `screenshots` と `metadata` しか消さないため、
  **そのままでは拡張側だけが hash をキーに残り続けます**。本家のクリーンアップに便乗して同じ条件で掃除します
  (本家は `res.json` をトランザクションの中で呼ぶので、同じトランザクションに乗り、後続の `VACUUM` で領域も回収されます)。
- 設定画面「拡張機能：メンテナンス（参照されていないデータ）」から、件数を確認して単独実行もできます。
- 対象: `ext_video_meta` / `ext_video_cover` / `ext_bookmarks` / `ext_related`。
  関連動画キャッシュは元動画が消えた行に加え、参照先が消えた行も対象です
  (`rel_hash` が NULL の「該当なし」印は元動画が生きていれば残します)。
- 出演者は「関連動画のない出演者を一括削除」が別にあるため対象外。タグサムネイルとブックマークフォルダは
  hash に紐づかないため対象外です。
- 実装: `server/ext/routes/maintenance.js`、`index.js` のフック、
  API `GET /ext/api/maintenance/orphans`, `POST /ext/api/maintenance/cleanup`。

## 拡張機能ON時の配色テーマ (WomanLiveEX)
拡張つきで起動中だと一目で分かるよう、表記と配色を変更します。
- **ヘッダー表記**: ロゴ「WomanLive」を「**WomanLiveEX**」に。
- **配色**: 本家の CSS 変数を上書き
  - ライト: 背景 `#F2F2F2` / 文字 `#685454` / アクセント `#EA8A8A`
  - ダーク: 背景 `#000000` / 文字 `#FFDEDE` / アクセント `#CF0F47`
  - `status-*`（成功/エラー等の意味色）は本家のまま変更しません。

## 無効化・アンインストール
- **一時無効化**: `womanlive-ext.bat` ではなく通常の `womanlive.bat` で起動すれば拡張は無効になります。
- **完全削除**: `server/ext/` フォルダと `womanlive-ext.bat` を削除。

## ファイル構成
```
server/ext/
  preload.js            本体無改変で拡張をロードするためのプリロード
  index.js              拡張のエントリ（ルート登録・注入ミドルウェア）
  db.js                 追加テーブルのスキーマ／共通ヘルパ
  inject.js             index.html への <script>/<link> 動的注入
  routes/               サーバー API
    cover.js            カバー画像・拡張設定
    meta.js             動画の拡張メタデータ
    search.js           拡張検索（評価/メーカー等）・シリーズ/公開カレンダー集計
    fullsearch.js       キーワード検索の拡張（表示動画名も照合）
    tags.js             タグ集計・タグサムネイル（タグ一覧用）
    screenshots.js      スクリーンショット枚数の集計
    related.js          関連動画（メタデータ類似・事前計算）
    performers.js       出演者 CRUD・画像・関連動画/SS・出演者タグプリセット
    tagrules.js         出演者タグ 自動付与ルール
    dmm.js              DMM(FANZA) 商品検索・メーカー検索
    makers.js           メーカー集計（本数/評価/TOP10タグ/レーベル）・メーカー情報・画像
    bookmark.js         ブックマーク（フォルダ/登録）
    bulk.js             一括操作（タグ/メタ/ブックマーク/削除）
    frame.js            コマ送り用のフレームレート取得（ffprobe）
    replace.js          メタデータの一括置換
    maintenance.js      参照されていない拡張データの掃除
    backup.js           追加データのエクスポート/インポート
  public/               ブラウザで動く拡張 UI（/ext/assets で配信）
    api.js              API クライアント
    namekey.js          名前ソート用の共通ソートキー（サーバー/クライアント共用 UMD）
    core.js             fetch フック・ルート検知・共通 UI（ダイアログ/チップ入力/クロッパ等）
    nav.js              ナビゲーション統一（単色アイコン/共通ヘッダー/メニュー/テーマ）
    homelinks.js        ホーム画面への追加リンク
    cover.js            カバー画像表示
    ssresize.js         スクリーンショット表示サイズ変更
    framestep.js        コマ送り（, / . キー・Shift+ホイール・タッチ端末のボタン）
    dispname.js         表示設定の「動画表示名で表示する」トグル
    videometa.js        動画ページの拡張メタ表示/編集・DMM検索FAB
    searchenh.js        検索ページの評価/スクショ数/表示名ソート・評価絞り込み
    screenshots.js      検索カードへスクショ枚数(カメラアイコン)を表示
    cardenh.js          検索カードのメーカー/評価/フォルダ名/出演者の表示拡張
    bulkselect.js       検索結果の選択モード・一括操作
    listselect.js       一覧ページの選択モード・一括削除
    performer.js        出演者ページ
    performerlist.js    出演者一覧
    makerlist.js        メーカー一覧（画像登録・情報編集・FANZAからの情報取得）
    serieslist.js       シリーズ一覧
    taglist.js          タグ一覧（サムネイル登録・タグ名/本数ソート・タグ検索）
    releasecal.js       公開カレンダー
    bookmark.js         ブックマーク追加ボタン/ダイアログ
    bookmarklist.js     ブックマーク一覧ページ
    settings.js         設定ページへの拡張セクション注入
    womanlive-ext.css   スタイル
```
